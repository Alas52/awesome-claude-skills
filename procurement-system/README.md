# 企业采购管理体系

## 概述

本采购管理体系适用于公司所有采购活动，包括但不限于宣传物料、办公用品、IT设备、服务采购等。本体系参考大型上市公司采购管理实践，旨在建立规范、透明、高效的采购流程。

## 体系架构

```
采购管理体系
├── 采购管理制度（本文档）
├── 采购流程规范
│   ├── 标准采购流程
│   ├── 紧急采购流程
│   └── 框架协议采购流程
├── 供应商管理体系
│   ├── 供应商准入
│   ├── 供应商评估
│   └── 供应商退出
├── 合同管理规范
└── 付款管理规范
```

## 组织架构

### 采购专员职责
- 供应商开发与管理
- 采购需求审核与执行
- 比价谈判
- 合同签订与归档
- 采购订单管理
- 供应商绩效评估
- 采购数据分析与报告

### 需求部门职责
- 提出采购需求
- 编制采购申请单
- 技术规格确认
- 到货验收
- 供应商评价反馈

### 财务部门职责
- 预算审核
- 合同审核（财务条款）
- 付款审批与执行
- 采购成本分析

### 法务部门职责（如有）
- 合同法律条款审核
- 法律风险评估
- 合同纠纷处理

## 采购分类管理

### 按金额分类

| 采购类别 | 金额范围 | 审批流程 | 供应商数量要求 |
|---------|---------|---------|--------------|
| 小额采购 | ≤5,000元 | 部门负责人审批 | 至少1家 |
| 一般采购 | 5,000-50,000元 | 部门负责人+采购专员+财务负责人 | 至少2家比价 |
| 重大采购 | 50,000-200,000元 | 部门负责人+采购专员+财务负责人+总经理 | 至少3家比价 |
| 特别重大采购 | >200,000元 | 董事会/CEO审批 | 至少3家比价+评标委员会 |

### 按类型分类

#### 1. 办公用品类
- 文具、纸张、耗材等
- 建议：建立框架协议，定期采购
- 付款方式：月结或季度结算

#### 2. IT设备类
- 电脑、打印机、服务器等
- 建议：制定标准配置清单
- 付款方式：货到付款或分期付款

#### 3. 宣传物料类
- 名片、宣传册、展架、礼品等
- 建议：保留样品库，建立合格供应商名录
- 付款方式：预付30% + 尾款70%

#### 4. 服务类
- 咨询服务、维修服务、外包服务等
- 建议：明确服务标准和验收标准
- 付款方式：按服务进度分期付款

#### 5. 固定资产类
- 办公家具、装修等
- 建议：严格预算控制，多轮比价
- 付款方式：验收合格后付款

## 核心采购流程

### 标准采购流程（8步法）

```
1. 需求提出 → 2. 需求审核 → 3. 供应商寻源 → 4. 询价比价 →
5. 审批决策 → 6. 合同签订 → 7. 订单执行 → 8. 验收付款
```

#### 第1步：需求提出
- **负责人**：需求部门
- **产出**：《采购申请单》
- **要点**：
  - 填写完整的采购申请单
  - 明确采购物品/服务的详细规格
  - 说明采购理由和用途
  - 填写预算金额和期望交付时间
  - 附上相关技术资料或参考样品

#### 第2步：需求审核
- **负责人**：采购专员 + 部门负责人
- **产出**：审核通过的采购申请
- **要点**：
  - 检查预算是否充足
  - 确认需求合理性
  - 评估紧急程度
  - 判断是否有替代方案
  - 确认技术参数是否明确

#### 第3步：供应商寻源
- **负责人**：采购专员
- **产出**：候选供应商清单
- **要点**：
  - 优先从合格供应商库选择
  - 新供应商需进行资质审核
  - 确保供应商数量符合比价要求
  - 评估供应商履约能力
  - 核实供应商营业执照、税务登记等资质

#### 第4步：询价比价
- **负责人**：采购专员
- **产出**：《比价分析表》
- **要点**：
  - 向供应商发送询价单（RFQ）
  - 统一询价截止时间
  - 记录报价明细（含税价、不含税价、交货期、付款条件等）
  - 进行多维度比较（价格、质量、交期、服务、历史表现）
  - 必要时组织现场谈判
  - 编制比价分析报告

#### 第5步：审批决策
- **负责人**：根据金额确定审批人
- **产出**：审批通过的采购方案
- **要点**：
  - 提交完整的审批资料（申请单、比价表、供应商资质等）
  - 说明供应商选择理由
  - 获得各级审批签字
  - 特殊情况说明（如单一来源采购）

#### 第6步：合同签订
- **负责人**：采购专员 + 法务（如需）
- **产出**：正式采购合同
- **要点**：
  - 使用公司标准合同模板
  - 明确标的物、数量、单价、总价
  - 约定交货时间、地点、方式
  - 明确验收标准
  - 约定付款条件和方式
  - 约定质保期和售后服务
  - 明确违约责任
  - 双方盖章并各执一份
  - 合同归档备案

#### 第7步：订单执行
- **负责人**：采购专员
- **产出**：采购订单（PO）
- **要点**：
  - 向供应商下达正式采购订单
  - 跟踪订单执行进度
  - 协调交货时间和地点
  - 解决执行过程中的问题
  - 提前通知需求部门准备验收

#### 第8步：验收付款
- **负责人**：需求部门（验收）+ 财务部门（付款）
- **产出**：验收单 + 付款凭证
- **要点**：
  - 需求部门进行质量和数量验收
  - 填写《验收单》并签字确认
  - 发现问题及时反馈采购专员处理
  - 采购专员整理付款资料（合同、订单、验收单、发票）
  - 提交财务部门审核付款
  - 财务按合同约定付款
  - 采购专员跟踪付款进度
  - 完成后归档所有单据

## 特殊采购流程

### 紧急采购流程
适用于突发情况下的紧急采购需求（如设备故障急需替换）

**简化流程**：
1. 需求部门提出紧急采购申请（说明紧急原因）
2. 部门负责人口头或邮件批准
3. 采购专员快速寻源（可降低供应商数量要求）
4. 总经理特批
5. 先采购后补签合同
6. 3个工作日内补齐所有审批手续

**注意**：紧急采购次数过多将影响部门KPI考核

### 框架协议采购
适用于长期、频繁、小额的采购（如办公用品、快消品）

**流程**：
1. 采购专员每年/每季度组织框架协议招标
2. 确定1-2家供应商签订框架协议
3. 约定价格、交货期、付款方式等
4. 日常采购时直接向框架协议供应商下单
5. 定期（月度/季度）统一结算付款
6. 年度评估供应商表现，决定是否续签

### 单一来源采购
适用于特定品牌、专利产品、售后服务等只能从唯一供应商采购的情况

**要求**：
1. 需求部门提供充分的单一来源说明
2. 采购专员核实确为单一来源
3. 报总经理特批
4. 保留相关证明材料（如品牌授权书、技术说明等）

## 供应商管理

### 供应商准入

#### 准入条件
1. **基本资质**：
   - 有效营业执照
   - 税务登记证明
   - 开户许可证/银行账户信息
   - 相关行业资质（如生产许可证等）

2. **经营状况**：
   - 成立时间≥1年（特殊情况除外）
   - 无重大法律纠纷
   - 无不良信用记录

3. **供应能力**：
   - 具备相应的生产/服务能力
   - 质量管理体系完善
   - 交付能力可靠

#### 准入流程
1. 供应商提交准入申请及资质材料
2. 采购专员审核资质
3. 必要时进行现场考察
4. 采购负责人审批
5. 录入合格供应商库
6. 签订《供应商廉洁协议》

### 供应商分类

| 类别 | 定义 | 管理策略 |
|-----|------|---------|
| 战略供应商 | 长期合作、金额大、重要度高 | 建立战略合作关系，年度商务洽谈，高层互访 |
| 重要供应商 | 交易频繁、质量稳定 | 签订框架协议，季度评估，保持稳定合作 |
| 一般供应商 | 偶尔合作、金额小 | 按需采购，基础管理 |
| 考察期供应商 | 新供应商 | 小批量试用，严格验收，3个月评估 |

### 供应商评估

#### 评估周期
- 战略供应商：每季度评估
- 重要供应商：每半年评估
- 一般供应商：每年评估或按交易评估

#### 评估维度

| 评估项 | 权重 | 评分标准 |
|-------|------|---------|
| 产品/服务质量 | 30% | 合格率、客户满意度、售后服务 |
| 价格竞争力 | 25% | 与市场价格对比、降价配合度 |
| 交付及时性 | 20% | 准时交货率、紧急响应能力 |
| 商务配合度 | 15% | 沟通响应、合同履约、账期支持 |
| 资质与合规 | 10% | 资质有效性、发票合规性、企业信用 |

#### 评估结果应用
- **优秀（≥90分）**：优先合作，可增加采购份额
- **良好（75-89分）**：继续合作
- **合格（60-74分）**：保留资格，提出改进要求
- **不合格（<60分）**：暂停合作或淘汰

### 供应商淘汰

以下情况将淘汰供应商：
1. 连续2次评估不合格
2. 发生重大质量事故
3. 严重延误交付（超过约定时间30天以上）
4. 存在商业贿赂、欺诈行为
5. 企业注销、破产或被吊销执照
6. 拒不配合整改

## 合同管理

### 合同签订原则
1. 所有≥5,000元的采购必须签订书面合同
2. <5,000元的小额采购可使用订单或确认邮件代替
3. 使用公司标准合同模板
4. 重大合同需法务审核
5. 合同由授权人员签署（总经理或授权代表）

### 合同必备条款
1. **双方信息**：完整的公司名称、地址、联系方式
2. **标的条款**：采购物品/服务的详细描述、规格、数量
3. **价格条款**：单价、总价、税率、币种
4. **交付条款**：交货时间、地点、方式、运费承担
5. **验收条款**：验收标准、验收期限、异议处理
6. **付款条款**：付款方式、付款时间、账户信息
7. **质保条款**：质保期、质保范围、维修响应时间
8. **违约责任**：违约情形、违约金、赔偿方式
9. **争议解决**：协商、仲裁或诉讼方式
10. **其他条款**：保密、不可抗力、合同生效等

### 合同审批权限

| 合同金额 | 审批权限 |
|---------|---------|
| <50,000元 | 采购专员起草 + 部门负责人审核 + 财务负责人确认 |
| 50,000-200,000元 | 采购专员起草 + 部门负责人审核 + 财务负责人确认 + 总经理审批 |
| >200,000元 | 采购专员起草 + 部门负责人审核 + 财务负责人确认 + 法务审核 + 总经理/CEO审批 |

### 合同归档
1. 合同原件由采购专员归档保管
2. 扫描件上传至采购管理系统
3. 相关部门保留复印件
4. 保存期限：合同履行完毕后至少5年

## 付款管理

### 付款方式

#### 预付款
- **适用**：定制产品、大额采购、新供应商
- **比例**：通常不超过合同金额的30%
- **要求**：供应商需提供相应担保或预付款发票

#### 货到付款
- **适用**：标准产品、成熟供应商、中小额采购
- **时间**：验收合格后7-15个工作日

#### 分期付款
- **适用**：大额采购、项目型采购
- **方式**：
  - 签约付30%
  - 交货验收付60%
  - 质保期满付10%

#### 账期结算
- **适用**：框架协议采购、长期合作供应商
- **周期**：月结30天、月结60天、季度结算等

### 付款流程

```
1. 采购专员整理付款资料 → 2. 需求部门确认验收 → 3. 采购专员提交付款申请 →
4. 财务审核 → 5. 审批人审批 → 6. 财务付款 → 7. 采购专员确认到账
```

### 付款资料清单
1. 采购合同（盖章版）
2. 采购订单
3. 验收单（需求部门签字）
4. 供应商发票（增值税专用发票或普通发票)
5. 送货单/签收单
6. 付款申请单
7. 其他（如银行账户信息、质检报告等）

### 付款审批权限

| 付款金额 | 审批流程 |
|---------|---------|
| <10,000元 | 采购专员 + 财务负责人 |
| 10,000-50,000元 | 采购专员 + 部门负责人 + 财务负责人 |
| 50,000-200,000元 | 采购专员 + 部门负责人 + 财务负责人 + 总经理 |
| >200,000元 | 采购专员 + 部门负责人 + 财务负责人 + 总经理 + CEO/CFO |

### 付款时效
1. 小额付款（<10,000元）：3个工作日
2. 一般付款（10,000-50,000元）：5个工作日
3. 重大付款（>50,000元）：7-10个工作日

## 采购监督与审计

### 内部控制
1. **职责分离**：申请、审批、采购、验收、付款由不同人员/部门负责
2. **流程留痕**：所有采购活动必须有书面记录或系统记录
3. **定期审计**：财务部门每季度抽查采购记录
4. **举报机制**：设立采购投诉邮箱/热线

### 廉洁要求
1. 采购人员不得收受供应商任何形式的回扣、礼品、宴请
2. 与供应商保持纯粹商业关系，避免利益关联
3. 发现供应商不当行为应及时上报
4. 违反廉洁规定的员工将予以辞退并追究法律责任

### 例外管理
特殊情况下可申请例外审批：
1. 紧急采购降低供应商数量要求
2. 单一来源采购
3. 超预算采购
4. 特殊付款条件

**要求**：必须提供充分理由，经总经理特批，事后补充说明

## 采购数据管理

### 采购系统
建议使用采购管理系统（或Excel管理），记录：
- 采购申请单
- 供应商信息库
- 合同台账
- 订单台账
- 付款台账
- 供应商评估记录

### 采购报表
采购专员每月/季度/年度提供：
1. **采购汇总表**：按类别、部门、供应商统计采购金额
2. **供应商分析表**：top供应商占比、新供应商数量
3. **成本分析表**：同比/环比价格变动分析
4. **执行情况表**：订单准时交付率、验收合格率
5. **预算执行表**：预算vs实际支出对比
