# 采购管理体系 - 快速实施指南

## 适用场景

本指南适用于准备设立采购专员岗位（0.5-1 HC）的中小型公司，主要采购内容包括：
- 宣传物料（名片、宣传册、展架、礼品等）
- 办公用品（文具、纸张、耗材等）
- IT设备（电脑、打印机、服务器等）
- 其他日常采购

---

## 第一步：岗位设置（第1周）

### 1.1 确定采购专员

**岗位名称**：采购专员（兼职0.5 HC或全职1 HC）

**岗位职责**：
- 供应商开发与管理
- 采购需求审核与执行
- 比价谈判
- 合同签订与归档
- 采购订单管理
- 供应商绩效评估
- 采购数据分析与报告

**任职要求**：
- 熟悉采购流程和供应商管理
- 良好的沟通谈判能力
- 细致认真，有责任心
- 熟练使用Excel等办公软件
- 廉洁自律，坚持原则

**汇报关系**：向行政负责人/财务负责人/总经理汇报

### 1.2 明确审批权限

根据公司实际情况，确定不同金额的审批权限（参考）：

| 采购金额 | 审批人 |
|---------|-------|
| ≤5,000元 | 部门负责人 |
| 5,000-50,000元 | 部门负责人 + 采购专员 + 财务负责人 |
| 50,000-200,000元 | 部门负责人 + 采购专员 + 财务负责人 + 总经理 |
| >200,000元 | 董事会/CEO |

## 第二步：制度发布（第2周）

### 2.1 学习采购制度

**必读文档**：
1. [采购管理制度总纲](./README.md) - 了解整体框架
2. [采购流程详解](./processes/采购流程详解.md) - 掌握具体操作
3. [供应商管理体系](./processes/供应商管理体系.md) - 学习供应商管理

**重点关注**：
- 8步采购流程：需求-审核-寻源-比价-审批-合同-订单-验收付款
- 不同金额的审批要求和供应商数量要求
- 供应商准入、评估、淘汰机制

### 2.2 定制化调整

根据公司实际情况，调整以下内容：
- **审批金额阈值**：根据公司规模调整（如小公司可简化为≤1万、1-10万、>10万三档）
- **供应商数量要求**：小公司可适当降低（如一般采购1-2家比价即可）
- **付款方式**：根据现金流情况确定主要付款方式
- **采购周期**：根据业务节奏确定（如按月、按季度等）

### 2.3 内部培训

**培训对象**：
- 采购专员（重点）
- 各部门负责人
- 财务部门
- 常提采购需求的员工

**培训内容**：
- 采购管理制度介绍
- 如何填写采购申请单
- 采购流程和时间要求
- 各部门职责和配合要求
- 廉洁纪律要求

**培训方式**：
- 集中培训会（1-2小时）
- 发布制度文件到公司内部系统
- 一对一辅导（针对高频采购部门）

## 第四步：供应商开发（第3-4周）

### 4.1 梳理现有供应商

**盘点现有供应商**：
- 列出目前合作的所有供应商
- 收集供应商资质（营业执照、税号、账户等）
- 评估现有供应商表现

**建档管理**：
- 为现有合格供应商建立档案
- 分配供应商编号
- 录入供应商信息库
- 签订《供应商廉洁协议》

### 4.2 开发新供应商

**按采购品类开发**：

#### IT设备类（目标：2-3家）
- 联想/戴尔/惠普官方经销商或代理商
- 京东企业购、天猫企业购
- 本地IT设备供应商

#### 办公用品类（目标：1-2家）
- 晨光、得力等品牌经销商
- 京东企业购、天猫企业购
- 本地办公用品批发商

#### 宣传物料类（目标：3-5家）
- 印刷厂（名片、宣传册）
- 广告制作公司（展架、海报）
- 礼品定制公司（企业礼品）
- 网络平台（如淘宝企业店）

**供应商开发流程**：
1. 网络搜索或同行推荐
2. 联系供应商，了解业务范围
3. 要求填写《供应商准入申请表》
4. 提供资质证明材料
5. 采购专员审核
6. 必要时现场考察
7. 审批通过，录入供应商库
8. 签订《供应商廉洁协议》
9. 设置3个月试用期

### 4.3 建立框架协议（可选）

**适用品类**：办公用品、快消品等高频采购

**框架协议内容**：
- 供应品类和价格清单
- 交货期（如2-3天）
- 付款方式（如月结30天）
- 起订量和配送要求
- 协议有效期（如1年）

**优势**：
- 简化日常采购流程
- 批量采购降低成本
- 统一结算提高效率

## 第五步：流程试运行（第5-8周）

### 5.1 从小额采购开始

**建议**：
- 第一批采购选择金额较小的项目（如办公用品、小额宣传物料）
- 完整走一遍流程，发现问题及时优化
- 积累经验后再处理大额采购

### 5.2 重点关注

**流程执行**：
- 所有采购必须填写采购申请单
- 严格执行审批流程，不得跳过
- 按要求进行比价（至少2-3家）
- ≥5000元必须签订合同
- 严格验收，不合格不付款
- 所有单据及时归档

**常见问题**：
- 需求部门不填申请单或填写不规范 → 退回要求重新填写
- 紧急采购要求简化流程 → 启用紧急采购流程，事后补手续
- 供应商要求预付款 → 评估必要性，一般不超过30%，需审批
- 验收不合格 → 要求供应商退换货，暂停付款

### 5.3 收集反馈

**定期收集反馈**（每周或每两周）：
- 需求部门：流程是否繁琐？时间是否及时？
- 财务部门：单据是否齐全？付款流程是否顺畅？
- 供应商：订单是否清晰？付款是否及时？

**持续优化**：
- 简化不必要的环节
- 优化表单格式
- 调整审批流程
- 完善制度细节

## 第六步：正式运行与持续改进（第9周起）

### 6.1 全面推广

**制度正式生效**：
- 发布正式通知，宣布采购制度正式实施
- 所有采购必须按新流程执行
- 旧的采购方式停止使用

**制度宣贯**：
- 定期提醒各部门遵守采购制度
- 对新员工进行采购流程培训
- 公布典型案例（好的案例表扬，违规案例通报）

### 6.2 定期评估

**月度总结**（采购专员）：
- 本月采购次数、金额汇总
- 各部门采购情况统计
- 主要供应商合作情况
- 流程执行中的问题和改进建议

**季度评估**（采购专员+财务）：
- 采购成本分析（同比、环比）
- 供应商评估（按《供应商评估表》）
- 预算执行情况
- 制度执行情况审计

**年度总结**（全面总结）：
- 年度采购总额和成本节约
- 供应商结构优化情况
- 制度执行情况和改进措施
- 下年度采购计划和目标

### 6.3 持续改进

**优化方向**：
- **电子化**：引入采购管理系统，实现在线申请、审批、跟踪
- **标准化**：制定标准配置清单（如员工电脑标配）
- **集中采购**：对高频采购实行集中采购或框架协议
- **供应商优化**：淘汰不合格供应商，培育优质供应商
- **成本控制**：定期比价，争取更优价格和条件

## 常见问题FAQ

**Q1：公司规模小，能否简化流程？**
A：可以。建议保留核心环节（申请-比价-审批-合同-验收-付款），适当降低要求（如小额采购1家报价即可，简化审批层级）。

**Q2：0.5 HC的采购专员如何安排工作？**
A：采购专员可以兼职（如行政专员兼任），日常处理采购事务，重大采购时全力投入。建议梳理高频采购，建立框架协议，减少日常工作量。

**Q3：没有采购管理系统怎么办？**
A：初期可用Excel管理，建立供应商信息库、采购台账、合同台账、付款台账。后期业务量增大可引入专业采购系统或ERP。

**Q4：供应商不愿意签廉洁协议怎么办？**
A：说明这是公司制度要求，所有供应商必须签订。不签订则无法成为合格供应商。绝大多数正规供应商都会签订。

**Q5：如何控制采购成本？**
A：
- 多家比价，引入竞争
- 批量采购，争取折扣
- 建立框架协议,锁定价格
- 定期评估供应商，淘汰价格高的
- 参考市场价格，避免被宰

**Q6：如何保证采购廉洁？**
A：
- 签订廉洁协议
- 流程透明，多人监督（申请、审批、验收、付款分离）
- 定期审计采购记录
- 设立举报渠道
- 对违规行为零容忍

**Q7：供应商要求预付款怎么办？**
A：
- 评估必要性（定制产品、大额采购一般需要）
- 预付比例通常不超过30%
- 要求供应商提供担保或履约保函
- 在合同中明确预付款条件和违约责任
- 需经财务审批

## 成功关键因素

### 1. 领导支持
- 总经理/CEO重视，支持采购规范化
- 带头执行采购制度，起示范作用

### 2. 制度落地
- 制度不能停留在纸面，必须真正执行
- 初期严格要求，培养习惯
- 对违规行为及时纠正

### 3. 持续优化
- 制度不是一成不变的，根据实际情况调整
- 听取各方反馈，持续改进
- 简化不必要的环节，提高效率

### 4. 供应商关系
- 建立稳定的供应商合作关系
- 及时付款，维护信誉
- 与优质供应商建立长期合作

### 5. 数据驱动
- 记录所有采购数据
- 定期分析，发现问题和机会
- 用数据指导决策
