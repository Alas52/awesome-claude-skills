# 采购流程详解

## 一、标准采购流程（完整版）

### 流程图

```
┌─────────────┐
│ 1.需求提出  │ 需求部门填写《采购申请单》
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 2.需求审核  │ 部门负责人审批 + 采购专员初审
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 3.供应商寻源│ 采购专员从供应商库选择或开发新供应商
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 4.询价比价  │ 向≥2家供应商询价，编制《比价分析表》
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 5.审批决策  │ 按金额不同层级审批
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 6.合同签订  │ 签订正式采购合同（≥5000元必须签合同）
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 7.订单执行  │ 下达采购订单(PO)，跟踪交付
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 8.验收付款  │ 需求部门验收 + 财务付款 + 单据归档
└─────────────┘
```

## 二、各环节详细操作指南

### 第1步：需求提出

#### 1.1 谁来提
- **需求部门**的具体用品使用人或部门负责人

#### 1.2 提什么
填写《采购申请单》，必填内容：
- [ ] 申请部门/人
- [ ] 申请日期
- [ ] 采购物品/服务名称
- [ ] 详细规格型号（越详细越好）
- [ ] 采购数量
- [ ] 预算金额（含税）
- [ ] 用途说明
- [ ] 期望交付时间
- [ ] 是否紧急
- [ ] 附件（技术参数、参考图片、样品等）

#### 1.3 注意事项
- 技术参数要明确，避免后期反复确认
- 预算要实事求是，参考市场价格
- 紧急采购需说明紧急原因
- 大额采购需提前规划，预留充足时间

#### 1.4 产出
- 《采购申请单》（需求部门负责人签字）

---

### 第2步：需求审核

#### 2.1 谁来审
- **部门负责人**：审核需求合理性和预算
- **采购专员**：审核技术参数完整性和市场可行性

#### 2.2 审什么
- [ ] 采购需求是否真实必要
- [ ] 预算是否充足且合理
- [ ] 技术参数是否明确
- [ ] 交付时间是否可行
- [ ] 是否有库存或替代方案
- [ ] 是否可以并入其他采购计划

#### 2.3 审核结果
- **通过**：进入下一流程
- **退回**：要求补充信息或调整需求
- **拒绝**：说明理由，不予采购

#### 2.4 产出
- 审核通过的《采购申请单》

---

### 第3步：供应商寻源

#### 3.1 谁来找
- **采购专员**

#### 3.2 怎么找

**方法一：从合格供应商库选择**
- 优先选择已合作且评价良好的供应商
- 根据供应商类别筛选（如IT设备类、办公用品类）
- 查看历史采购记录和评价

**方法二：开发新供应商**
适用于：
- 供应商库无相应类别
- 现有供应商报价过高
- 需要引入竞争

开发渠道：
- 网络搜索（企业官网、B2B平台）
- 同行推荐
- 行业展会
- 招标公告

**新供应商准入流程**：
1. 供应商填写《供应商准入申请表》
2. 提供资质证明（营业执照、税务登记、行业资质等）
3. 采购专员审核资质
4. 必要时现场考察（大额采购或重要供应商）
5. 采购负责人审批
6. 录入合格供应商库
7. 签署《廉洁协议》

#### 3.3 选多少家
根据采购金额确定：
- 小额采购（≤5,000元）：≥1家
- 一般采购（5,000-50,000元）：≥2家
- 重大采购（50,000-200,000元）：≥3家
- 特别重大采购（>200,000元）：≥3家 + 评标委员会

#### 3.4 产出
- 候选供应商清单（含联系方式、资质证明）

---

### 第4步：询价比价

#### 4.1 谁来做
- **采购专员**

#### 4.2 询价步骤

**Step 1：编制询价单（RFQ - Request for Quotation）**
询价单内容：
- 公司名称
- 询价日期
- 采购物品/服务详细描述
- 技术规格要求
- 采购数量
- 期望交付时间和地点
- 付款方式偏好
- 报价截止时间
- 联系人和联系方式

**Step 2：发送询价单**
- 同时向所有候选供应商发送
- 统一询价截止时间（一般3-5个工作日）
- 要求供应商按统一格式报价

**Step 3：接收报价**
要求供应商提供：
- [ ] 含税单价和总价
- [ ] 不含税单价和总价
- [ ] 税率
- [ ] 交货期
- [ ] 付款条件
- [ ] 质保期和售后服务
- [ ] 报价有效期
- [ ] 其他费用（运费、安装费等）

**Step 4：比价分析**
编制《比价分析表》，多维度对比：

| 对比项 | 供应商A | 供应商B | 供应商C |
|-------|---------|---------|---------|
| 含税总价 | | | |
| 不含税总价 | | | |
| 单价 | | | |
| 交货期 | | | |
| 付款条件 | | | |
| 质保期 | | | |
| 品牌/质量 | | | |
| 历史合作情况 | | | |
| 售后服务 | | | |
| **综合评分** | | | |

**Step 5：价格谈判**（必要时）
- 发现报价偏高时，与供应商谈判
- 大额采购组织多轮报价或现场议价
- 记录谈判过程和最终价格

#### 4.3 比价原则
- **不唯价格论**：最低价不一定是最佳选择
- **综合评估**：价格、质量、交期、服务等综合考量
- **历史表现**：优先选择合作良好的供应商
- **风险控制**：避免过度依赖单一供应商

#### 4.4 特殊说明

**价格差异超过20%时**：
- 核实规格是否一致
- 了解差异原因（品牌、质量、服务等）
- 向价格偏高的供应商争取降价
- 向价格偏低的供应商确认质量保证

**无法比价情况**：
- 单一来源采购：需说明理由，报特批
- 紧急采购：可降低供应商数量，事后补充说明

#### 4.5 产出
- 《比价分析表》（含供应商报价单、分析结论、推荐意见）

---

### 第5步：审批决策

#### 5.1 谁来批
根据采购金额确定审批人：

| 金额范围 | 审批流程 |
|---------|---------|
| ≤5,000元 | 部门负责人 |
| 5,000-50,000元 | 部门负责人 + 采购专员 + 财务负责人 |
| 50,000-200,000元 | 部门负责人 + 采购专员 + 财务负责人 + 总经理 |
| >200,000元 | 董事会/CEO + 评标委员会 |

#### 5.2 批什么
审批资料包：
- [ ] 《采购申请单》（需求部门负责人签字）
- [ ] 《比价分析表》
- [ ] 供应商报价单原件
- [ ] 供应商资质证明（新供应商）
- [ ] 推荐供应商及理由说明
- [ ] 技术参数确认文件
- [ ] 预算确认

#### 5.3 审批要点
- 核对预算是否充足
- 确认供应商选择合理
- 检查比价过程是否规范
- 特殊情况（单一来源、紧急采购）说明是否充分

#### 5.4 审批方式
- 线上：采购系统流程审批
- 线下：纸质单据签字审批
- 紧急：可先口头/邮件批准,后补签字

#### 5.5 产出
- 审批通过的采购方案（所有审批人签字）

---

### 第6步：合同签订

#### 6.1 谁来签
- **起草**：采购专员
- **审核**：部门负责人 + 财务负责人 +（法务部门，如需）
- **签署**：总经理或授权代表

#### 6.2 签什么

**合同签订规则**：
- ≥5,000元：必须签订书面合同
- <5,000元：可用采购订单或邮件确认代替
- >200,000元：必须法务审核

#### 6.3 合同模板选择

根据采购类型选择：
- **标准产品采购**：《标准采购合同》
- **服务采购**：《服务采购合同》
- **长期框架协议**：《框架协议》
- **定制产品**：在标准合同基础上增加定制条款

#### 6.4 合同必备条款

**10大必备条款**：
1. **合同主体**：甲乙双方完整名称、地址、联系方式
2. **标的条款**：采购物品/服务详细描述、规格、数量
3. **价格条款**：单价、总价、税率（明确含税或不含税）
4. **交付条款**：
   - 交付时间（具体日期或合同签订后X天）
   - 交付地点
   - 运输方式
   - 运费承担
5. **验收条款**：
   - 验收标准（质量、数量、外观等）
   - 验收期限（货到后X天内）
   - 验收方式（现场验收或书面验收）
   - 不合格品处理（退换货、维修、赔偿）
6. **付款条款**：
   - 付款方式（预付、货到付款、分期、账期）
   - 付款时间（验收合格后X天、月结等）
   - 收款账户信息
   - 发票要求（专票或普票、开票时间）
7. **质保条款**：
   - 质保期（1年、3年等）
   - 质保范围（免费维修、换货）
   - 售后服务响应时间（24小时、48小时）
   - 质保期外服务政策
8. **违约责任**：
   - 延迟交货违约金（每日合同总额的X%）
   - 质量不合格违约金
   - 付款延迟违约金
   - 违约赔偿上限
9. **争议解决**：
   - 协商解决
   - 仲裁或诉讼（约定管辖地）
10. **其他条款**：
    - 保密条款（如需）
    - 不可抗力
    - 合同变更和解除
    - 合同份数和生效条件

#### 6.5 合同签订流程

```
采购专员起草合同
     ↓
需求部门确认技术条款
     ↓
财务部门确认财务条款
     ↓
法务审核（重大合同）
     ↓
公司授权人签字盖章
     ↓
发送供应商签字盖章
     ↓
收回盖章版合同
     ↓
合同归档（原件+扫描件）
```

#### 6.6 合同管理

**合同编号规则**：
CG-YYYYMMDD-XXX
- CG：采购合同
- YYYYMMDD：签订日期
- XXX：流水号

**合同归档**：
- 原件：采购专员保管（锁柜）
- 扫描件：上传采购系统
- 复印件：需求部门、财务部门各留存一份
- 保存期限：合同履行完毕后至少5年

**合同台账**：
记录所有合同信息，包括：
- 合同编号
- 签订日期
- 供应商名称
- 采购内容
- 合同金额
- 履行状态（执行中/已完成/已终止）
- 付款情况
- 归档位置

#### 6.7 产出
- 正式签订的采购合同（双方盖章）

---

### 第7步：订单执行

#### 7.1 谁来做
- **主导**：采购专员
- **配合**：需求部门、供应商

#### 7.2 下采购订单（PO）

**采购订单内容**：
- 订单编号：PO-YYYYMMDD-XXX
- 订单日期
- 供应商信息
- 采购物品明细（名称、规格、数量、单价、总价）
- 交货时间和地点
- 联系人信息
- 付款条件
- 特殊要求

**发送方式**：
- 邮件发送（留存记录）
- 或通过采购系统生成并推送

**供应商确认**：
- 要求供应商回复确认接单
- 确认交货时间
- 确认交货地点和联系人

#### 7.3 订单跟踪

**采购专员的跟踪职责**：

| 时间节点 | 跟踪动作 |
|---------|---------|
| 下单后1-2天 | 确认供应商是否接单，是否安排生产/发货 |
| 交货前3天 | 确认交货准确时间，通知需求部门准备验收 |
| 预计交货日 | 跟踪物流或供应商，确保按时交付 |
| 延迟交货时 | 督促供应商，了解延迟原因和预计交货时间 |
| 货物到达后 | 通知需求部门及时验收 |

**跟踪工具**：
- 订单跟踪表（Excel或采购系统）
- 与供应商沟通记录（邮件、电话、微信等需留痕）
- 物流追踪信息

#### 7.4 异常处理

**常见异常及处理**：

| 异常情况 | 处理方案 |
|---------|---------|
| 供应商延迟交货 | 1. 了解原因和预计时间<br>2. 评估对业务影响<br>3. 要求供应商承诺并加快<br>4. 严重延迟追究违约责任 |
| 供应商单方变更价格 | 1. 拒绝变更，坚持合同价格<br>2. 协商解决，必要时寻找替代供应商 |
| 供应商质量问题 | 1. 暂停收货<br>2. 要求整改或退换货<br>3. 追究违约责任 |
| 需求部门变更需求 | 1. 评估变更影响<br>2. 与供应商协商<br>3. 签订补充协议<br>4. 调整订单或取消重下 |
| 无法联系供应商 | 1. 多渠道联系（电话、邮件、上门）<br>2. 启动应急采购<br>3. 供应商列入黑名单 |

#### 7.5 收货协调
- 提前告知需求部门收货时间
- 确认收货地点和验收人
- 大件货物协调搬运和存放
- 特殊物品（如危险品、冷链）做好接收准备

#### 7.6 产出
- 采购订单（PO）
- 订单跟踪记录
- 送货单/签收单

---

### 第8步：验收付款

#### 8.1 验收环节

**8.1.1 谁来验收**
- **主验收人**：需求部门使用人或部门负责人
- **监督人**：采购专员（必要时参与）

**8.1.2 验收标准**
按合同约定的验收条款执行：
- [ ] **数量验收**：清点数量是否与订单一致
- [ ] **外观验收**：包装是否完好，有无破损
- [ ] **规格验收**：型号、规格是否与订单一致
- [ ] **质量验收**：
  - 办公用品：检查质量、品牌
  - IT设备：开箱检查外观、通电测试、系统测试
  - 宣传物料：检查印刷质量、颜色、尺寸
  - 服务：检查服务完成情况、交付成果
- [ ] **附件验收**：配件、说明书、保修卡等是否齐全
- [ ] **发票验收**：发票信息是否正确（抬头、税号、金额、品名）

**8.1.3 验收期限**
- 标准产品：货到后3个工作日内
- IT设备：货到后5个工作日内（需测试）
- 服务：服务完成后3个工作日内
- 特殊约定：按合同约定

**8.1.4 验收结果**

**验收合格**：
- 填写《验收单》，验收人签字确认
- 注明验收日期
- 交采购专员归档并准备付款

**验收不合格**：
- 填写《验收不合格通知单》，说明不合格原因
- 拍照留证
- 采购专员联系供应商处理：
  - 轻微问题：要求折扣或部分退款
  - 严重问题：要求退换货
  - 拒收：要求供应商取回货物，追究违约责任
- 重新验收合格后才能付款

#### 8.2 付款环节

**8.2.1 谁来付**
- **整理资料**：采购专员
- **审核**：财务部门
- **审批**：根据金额确定审批人
- **执行付款**：出纳

**8.2.2 付款资料清单**
采购专员需提交完整的付款资料包：
- [ ] 《付款申请单》（采购专员填写）
- [ ] 采购合同（盖章扫描件或原件复印件）
- [ ] 采购订单（PO）
- [ ] 验收单（需求部门签字）
- [ ] 供应商发票（增值税专用发票或普通发票）
- [ ] 送货单/签收单
- [ ] 供应商银行账户信息
- [ ] 其他（质检报告、安装调试报告等，如需）

**8.2.3 付款审批流程**

```
采购专员整理资料并填写《付款申请单》
     ↓
需求部门确认已验收
     ↓
财务部门审核资料完整性、发票真实性、金额准确性
     ↓
按金额确定审批人审批
     ↓
出纳执行付款
     ↓
采购专员确认供应商到账
     ↓
所有资料归档
```

**8.2.4 付款审批权限**

| 付款金额 | 审批流程 |
|---------|---------|
| <10,000元 | 采购专员 + 财务负责人 |
| 10,000-50,000元 | 采购专员 + 部门负责人 + 财务负责人 |
| 50,000-200,000元 | 采购专员 + 部门负责人 + 财务负责人 + 总经理 |
| >200,000元 | 采购专员 + 部门负责人 + 财务负责人 + 总经理 + CEO/CFO |

**8.2.5 付款时效**
- 小额付款（<10,000元）：资料齐全后3个工作日内
- 一般付款（10,000-50,000元）：5个工作日内
- 重大付款（>50,000元）：7-10个工作日内
- 特殊付款（预付款、紧急付款）：特事特办

**8.2.6 付款方式**
- **对公转账**（主要方式）：银行转账到供应商对公账户
- **支付宝/微信**：仅限小额紧急采购（<1,000元），需特批
- **现金**：原则上不使用，特殊情况需总经理特批
- **银行承兑汇票**：大额采购可协商使用

**8.2.7 发票管理**
- 发票类型：优先要求增值税专用发票（可抵扣）
- 发票信息核对：
  - 抬头、税号是否正确
  - 金额是否与合同一致
  - 品名是否清晰
  - 开票日期是否合理
- 发票验真：登录税务系统验证发票真伪
- 发票归档：原件交财务部门入账，复印件采购专员留存

#### 8.3 单据归档

**8.3.1 归档责任人**
- **采购专员**：归档采购全流程单据

**8.3.2 归档内容**
完整的采购档案应包括：
- 采购申请单
- 比价分析表（含供应商报价单）
- 审批记录
- 采购合同
- 采购订单（PO）
- 供应商沟通记录（重要邮件打印）
- 送货单/签收单
- 验收单
- 付款申请单
- 付款凭证（银行回单）
- 发票（复印件）
- 其他相关资料

**8.3.3 归档方式**
- **纸质档案**：按采购订单或合同编号整理，放入档案袋，存放在档案柜
- **电子档案**：扫描所有纸质单据，按文件夹整理，上传采购系统或公司云盘
- **归档时间**：付款完成后3个工作日内完成归档
- **保存期限**：至少5年

#### 8.4 采购后评估

**8.4.1 评估时机**
- 每笔采购完成后
- 定期（季度/年度）汇总评估

**8.4.2 评估内容**
- 供应商表现评分（见供应商评估表）
- 采购价格是否合理（与历史价格、市场价格对比）
- 采购周期是否合理
- 流程是否顺畅，哪些环节可优化
- 成本节约情况

**8.4.3 结果应用**
- 供应商评分录入供应商档案，作为下次选择依据
- 优秀供应商可增加采购份额或签订框架协议
- 不合格供应商列入观察名单或淘汰
- 流程问题反馈，优化采购制度

#### 8.5 产出
- 验收单
- 付款凭证
- 完整的采购档案

## 三、不同采购场景流程

### 场景1：办公用品采购（框架协议模式）

```
月初：需求部门汇总本月办公用品需求
  ↓
需求部门填写《月度办公用品采购清单》，部门负责人审批
  ↓
采购专员汇总各部门需求，向框架协议供应商下单
  ↓
供应商3天内送货
  ↓
前台或行政人员签收，按部门分发
  ↓
月末：采购专员与供应商对账
  ↓
财务部门月结付款（次月10日前）
```

**优点**：简化流程，快速响应，统一采购降低成本

---

### 场景2：IT设备采购（标准流程）

```
员工入职或设备升级 → IT部门提出采购需求
  ↓
填写《采购申请单》（明确配置：CPU、内存、硬盘、屏幕等）
  ↓
IT负责人审批
  ↓
采购专员询价（联想、戴尔、惠普等至少3家）
  ↓
比价后推荐方案（考虑性价比、售后服务、交货期）
  ↓
总经理审批（假设单价8000元，采购5台，总额40,000元）
  ↓
签订采购合同
  ↓
供应商10天内送货
  ↓
IT部门验收（开箱检查、系统测试、性能测试）
  ↓
验收合格，开具发票
  ↓
财务部门付款（货到付款，验收后7天）
  ↓
IT部门做资产登记，采购专员归档
```

---

### 场景3：宣传物料采购（定制类）

```
市场部策划活动 → 确定需要制作宣传物料（如易拉宝10个）
  ↓
市场部填写《采购申请单》，附上设计稿
  ↓
采购专员联系2-3家广告制作供应商
  ↓
供应商提供报价 + 材质样品
  ↓
市场部确认材质和工艺
  ↓
采购专员比价，推荐性价比最优供应商
  ↓
市场负责人审批
  ↓
签订合同，预付30%定金
  ↓
供应商制作，3天后交付小样
  ↓
市场部确认小样OK，供应商批量制作
  ↓
5天后送货
  ↓
市场部验收（检查尺寸、印刷质量、颜色）
  ↓
验收合格，付尾款70%
  ↓
归档（保留样品照片）
```

---

### 场景4：紧急采购（投影仪故障需紧急更换）

```
周一早上9点：会议室投影仪突然故障，当天下午有重要客户演示
  ↓
行政部紧急采购申请（邮件或电话）给总经理
  ↓
总经理口头批准，授权采购专员紧急采购
  ↓
采购专员立即联系供应商（优先选择合作过的IT设备供应商）
  ↓
供应商报价，采购专员确认型号和价格合理（无需多家比价）
  ↓
确认2小时内能送货
  ↓
口头下单
  ↓
11点供应商送货，行政部验收
  ↓
验收合格，当天下午正常使用
  ↓
3个工作日内补签合同、补齐审批手续、安排付款
  ↓
归档时注明"紧急采购"
```

**注意**：紧急采购虽简化流程,但事后必须补齐手续，且需控制频次

---

### 场景5：服务采购（法律咨询服务）

```
公司遇到法律纠纷 → 需要聘请外部律师事务所
  ↓
法务部门（或总经办）提出采购申请
  ↓
说明服务内容、预算、期望结果
  ↓
采购专员联系2-3家律所
  ↓
律所提交服务方案 + 报价（服务范围、收费方式、预计费用）
  ↓
组织内部评审（法务、财务、总经理）
  ↓
选定律所，总经理审批
  ↓
签订《法律服务合同》（明确服务范围、费用、付款方式、成果交付标准）
  ↓
律所提供服务（阶段性沟通进展）
  ↓
服务完成，律所提交成果文件（如法律意见书、诉讼代理等）
  ↓
法务部门验收（检查成果质量、是否达到预期）
  ↓
验收合格，律所开具发票
  ↓
财务部门付款（通常分期：启动付30%，结案付70%）
  ↓
归档（合同、成果文件、付款凭证）
```

## 四、流程优化建议

### 4.1 电子化管理
- 使用采购管理系统（如SRM系统、ERP采购模块、钉钉/企微审批）
- 实现在线申请、在线审批、在线跟踪
- 减少纸质单据，提高效率

### 4.2 框架协议优先
- 对高频采购（办公用品、低值易耗品）建立框架协议
- 定期招标，确定1-2家供应商
- 简化日常采购流程

### 4.3 标准化管理
- 制定标准配置清单（如员工电脑标准配置）
- 统一办公用品品牌和规格
- 减少选型时间，利于批量采购降低成本

### 4.4 供应商关系管理
- 建立核心供应商伙伴关系
- 定期沟通，了解市场动态
- 争取更优价格和服务

### 4.5 数据分析驱动
- 定期分析采购数据（品类、金额、供应商集中度等）
- 发现成本节约机会
- 优化供应商结构

## 五、常见问题FAQ

**Q1：如果需求很紧急，来不及走完整流程怎么办？**
A：启用紧急采购流程，但必须：
- 说明紧急原因
- 获得上级口头或邮件批准
- 先采购后补手续
- 3个工作日内补齐所有审批和合同

**Q2：只有一家供应商能提供，无法比价怎么办？**
A：申请单一来源采购：
- 提供充分说明（如独家代理、专利产品、售后服务等）
- 报总经理特批
- 与该供应商充分谈判，争取合理价格
- 保留证明材料

**Q3：供应商延迟交货怎么办？**
A：
- 了解延迟原因和预计交货时间
- 评估对业务影响
- 轻微延迟（3天内）：督促供应商加快
- 严重延迟：追究违约责任，扣除违约金，或寻找替代供应商

**Q4：验收不合格怎么办？**
A：
- 填写《验收不合格通知单》，拍照留证
- 联系供应商退换货或整改
- 重新验收合格后才付款
- 严重质量问题追究违约责任，必要时淘汰该供应商

**Q5：供应商要求预付款怎么办？**
A：
- 评估必要性（定制产品、大额采购一般需预付）
- 预付比例通常不超过30%
- 要求供应商提供担保（如履约保函）
- 在合同中明确预付款条件和违约责任
- 财务审批预付款

**Q6：发现供应商发票有问题怎么办？**
A：
- 暂停付款
- 要求供应商重新开具正确发票
- 财务部门验证发票真伪
- 发票合规后再付款

**Q7：同一供应商能否长期合作？**
A：可以，但需要：
- 定期评估供应商表现
- 保持2-3家供应商竞争，避免过度依赖
- 定期比价，确保价格合理
- 签订框架协议，约定降价机制

**Q8：采购专员可以自己决定选择哪家供应商吗？**
A：不可以，必须：
- 提供客观的比价分析
- 给出推荐意见和理由
- 由审批人最终决策
- 确保采购透明和廉洁

**流程优化方向**：简化不必要的环节，强化风险控制关键点
